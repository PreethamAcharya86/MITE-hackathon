Guidelines

Rules & Regulations

Know the rules before you build — fair play makes the best hackathon.

Team Size

Teams must consist of 2 to 3 members. Solo participants are not allowed. Form your squad wisely!

Time Limit

All coding must happen within the official 6-hour window (10:00 AM – 4:00 PM). No pre-built projects.

GitHub Requirements

Every team member must have an individual GitHub account. The project repository must be created only after the event officially begins.

Original Work

Plagiarism is strictly prohibited. All code must be original.

Judging Criteria

Projects are judged on Innovation, Technical Complexity, Impact and Presentation. Judges' decisions are final, and there are no tie-breakers.

Submission

All teams must submit their project demo and GitHub link via the official form before the deadline.
