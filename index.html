Event Timeline

Your 6-hour journey mapped out minute by minute

09:15 AM – 09:30 AM

Reporting, Desk Setup & Power/Wi-Fi Verification

Teams report to the venue, settle into assigned workstations, setup hardware, and verify power outlets and high-speed Wi-Fi connectivity.

Desk Setup
09:30 AM – 09:45 AM

Keynote, Rules & Reveal of On-Spot Problem Statements

Official keynote by the AIML Department. Hackathon rules, evaluation rubric, and the surprise on-spot challenge statements are revealed.

Challenge Reveal
09:45 AM – 10:00 AM

Ideation & Repository Setup (Vibe Begins)

Strategy brainstorming, solution architecture planning, GitHub repository initialization, and team role distribution. The vibe begins!

Vibe Begins
10:00 AM – 01:00 PM

⚡ Core Sprint 1: Prompting, API Integration & UI Build

3-hour high-intensity build sprint! Prompt engineering, LLM & AI API integration, core application logic, and rapid UI development.

Core Sprint 1
01:00 PM – 01:45 PM

Lunch Break (Staggered / Networking)

Recharge with lunch, exchange ideas with fellow builders, network with faculty and peer innovators, and align afternoon sprint goals.

Networking Break
01:45 PM – 03:30 PM

🚀 Core Sprint 2: Feature Freeze, Debugging & Deployment

Final build sprint! Lock in features, perform comprehensive debugging, and deploy live prototypes on Vercel, Render, or cloud environments.

Feature Freeze & Deploy
03:30 PM – 04:00 PM

🏆 Live Demos & Speed Judging

High-speed judging showdown! 2-minute elevator pitches per desk, real-time live demonstrations to the panel, jury scoring, and wrap-up.

Speed Judging
